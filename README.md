# npc-chat

Planned desktop app for AI character chat that reacts to live streams, with an OBS overlay. The intended stack is Electron, React, TypeScript, and Vite.

## Current state: Batch 0 only

This repository contains project instructions and four locally authored skills. Local Git has been initialized; there is no application, scaffold, package manifest, dependency set, or CI configuration.

There are no runnable install, build, or application test commands yet. Documentation checks are not application tests.

## Intent, not implementation

- Local, Remote, and Mixed modes are planned; their exact semantics remain undecided.
- The first future compatibility experiments are intended to explore using the owner's ChatGPT subscription through Codex App Server.
- That integration, account entitlement, and subscription compatibility are **UNVALIDATED**. Any probe requires separate authorization; Batch 0 does not run Codex or authenticate.
